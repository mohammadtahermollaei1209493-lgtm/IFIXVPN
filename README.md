## 📖 About The Project

**IFIXVPN** is a modern Android network client focused on **stable, secure connectivity** with a clean Persian-friendly interface.

One-tap connection, smart route selection, in-app license management, and official updates — built for everyday use.

---

## ✨ Key Features

* 🔗 **One-tap connect** — start secure tunneling in seconds  
* ⚡ **Smart route selection** — prefer lower latency configs automatically  
* 🔑 **License system** — activate and manage subscription inside the app  
* 📱 **Device limits** — control how many devices use each license  
* 🔄 **In-app updates** — download the latest version from the official panel  
* 🌙 **Dark UI** — modern, focused interface  
* 🇮🇷 **Persian support** — full RTL experience and local support channel
